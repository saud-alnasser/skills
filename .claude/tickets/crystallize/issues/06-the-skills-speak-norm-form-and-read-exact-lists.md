## Problem

The shipped skills restate reasoning their guides now carry as one-line whys,
reference the permissive may-read semantics, and are themselves essays — a stage
invocation loads the skill body plus its guides, so the skill body is part of
the same token budget and the same read-past risk.

## Outcome

Every shipped skill and dispatched-role definition converts to norm form,
loads by its exact list, and drops text the converted guides now own. What a
skill states is only what is that skill's to state.

## Acceptance

- Each skill body is norms with one-line whys; no skill instructs judged guide
  selection; no skill restates a norm a guide in its list owns.
- Conversion uses the manifest mechanism the pilot proved: each skill's norms
  inventoried, every row guarded and fire-checked, and each norm another
  surface now owns names its new single home.
- Suite guards updated in the same pass; the suite passes.
- Measured skill-body totals are materially smaller than before conversion.
