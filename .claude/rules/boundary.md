# The repository boundary

**This session works on one repository. Work for any other leaves as a report.**

| In another repository | |
| --- | --- |
| reading its files, history, issues | **allowed** — a claim is checked by reading what makes it |
| writing or editing a file | **not allowed** |
| planning its work — a spec, a ticket, a design | **not allowed** |
| entering a stage for it | **not allowed** |

- **The deliverable is the write-up, handed to whoever works there** — finished when the report is written, not when the change is made.
- **A finding about another repository is a report, not an options list** — a diagnosis offered with options becomes a proposal this session then owns. State what was found, what it costs, and what would close it — **do not offer to do it**, nor recommend this session as the place.
- **Authorization does not transfer** — told to fix something is not told to fix it *here*: where the session stands is a fact about the session, not the work. Ask if genuinely unclear.
- **Say it when it is reached, in that turn** — the failure is a chain of individually authorised steps with no obvious stop; naming the crossing gives the user one; it costs a sentence.
- **A clean position report licenses none of this** — it answers *has this repository moved under me*, never *is it mine to change*.
