# Evidence

## Throwaway prototype code is not evidence

- **Throwaway prototype code is not evidence** — code goes to `.claude/position/prototypes/` and is deleted; the write-up is an evidence record and is kept. Ignoring the code is the intent; ignoring the record of what it proved is silent data loss.
