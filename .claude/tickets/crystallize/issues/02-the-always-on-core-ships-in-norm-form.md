## Problem

The always-on tier is missing exactly the norms whose absence causes drift: the
entry table sits behind a pointer, so classification happens without it in
sight; nothing states that a settled question is acted on rather than asked; and
nothing yet defines what framework ownership binds a session to. Meanwhile the
four shipped rules carry their essays on every turn.

## Outcome

The shipped always-on surfaces — the CLAUDE.md template and the unscoped rule
templates — are rewritten to norm form and gain three members: the entry table,
the no-ask rule (a loaded norm that settles a question is acted on, citing the
line; asking is for genuine forks only), and the fixed-owner rule (a
framework-owned file is followed as written, never healed, never debated;
variation enters through declared points; a deviation is declared and loud).
Every existing norm in those files survives; every essay moves to the framework
repository's records or dies as redundant.

## Acceptance

- A turn that loads only the always-on tier can classify a request against the
  entry table without opening the router.
- Each always-on norm is an imperative or table carrying a one-line reason; none
  exceeds it into essay.
- Conversion uses the manifest mechanism the pilot proved: norms inventoried
  before rewriting, every row guarded, every guard fire-checked, no norm
  dropped.
- The installed always-on tier is measurably smaller than before despite the
  three additions.
