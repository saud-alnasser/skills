## sources closes at no hops

Provenance is followed deliberately or not at all, so a closure never walks it.
The record exists rather than being left out because a depth nobody declared and
a depth declared as zero read identically from the store and differently to a
reader: the first looks like an edge somebody forgot, and this one says what was
decided. It is also the field that is not an id — a pointer names a path, and
the Codebase has no ids — so there is nothing on the far end of it to return.
