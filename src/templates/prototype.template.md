# Template — prototype

Copy to `efforts/<effort>/evidence/prototypes/<hypothesis-slug>.md`.

**Write the first two sections before building.** A prototype with no stated
falsifier confirms whatever you were hoping for.

```markdown
---

---

# Hypothesis
What you believe, stated so it could be wrong.

# Falsifier
What you would have to see to abandon it. Written before the experiment.

# Experiment
What you built, where, and how you ran it. Enough that someone could repeat it.

# Observation
What actually happened — including the parts that surprised you.

# Result
Confirmed or refuted, against the falsifier above.

# Conclusion
What this means for the effort. If the answer is "no", say so plainly: a rejected
approach nobody wrote down gets proposed again in six weeks.

# Disposition of the code
Deleted. If any of it is to be promoted, say which idea — never which files —
and record the promotion decision in the spec. What ships is rewritten.
```

**The evidence file survives; the code does not.** Keeping prototype code
converts a learning tool into a liability that nobody remembers is one.
