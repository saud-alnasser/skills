## part-of closes to the effort root

The effort is the unit a ticket is read in, so the walk continues until a record
declares no parent — which along this edge is as far as there is to go. It is
declared as closing fully rather than as a second word meaning the same walk: a
vocabulary carrying two names for one behaviour is drift with nothing to catch
it, since no run could ever tell them apart.
